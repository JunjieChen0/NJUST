# 独立验收任务集

版本 `independent-acceptance-1.0.3`，SDK 为 Cangjie 1.0.5。库存与文本统计两个工程覆盖2项功能修改、2项修复、2项只读定位和2项只检查失败报告。

本清单由实现者编写，属于独立场景验收，不能作为第三方盲测。严格盲测需由未参与实现的人另行封存清单、工程和隐藏测试。

模型只看到起始工程、需求与允许修改的文件范围；隐藏测试在交付后的工程副本中执行。每项使用全新工作区和 VS Code profile。
只读任务禁止源码变化；修复任务禁止修改测试；功能任务要求真实系统验证、允许范围内的修改、新增测试和独立行为测试通过。
参考实现只用于验证评分器，不能计作模型成功。真实模型成绩必须保留消息、diff、验证记录和断言证据。

1.0.2 的首轮真实模型对照发现：H05 隐藏测试漏查 `countExact` 对制表符和换行的旧行为。1.0.3 补充兼容性断言；参考实现通过，已发现的错误交付被拒绝。1.0.2 原始报告保留，复核结果单列，不能混用两个评分版本。
